# 🏥 인하대병원 의료장비 조회 시스템 (Inha University Hospital Medical Equipment Inquiry System)

인하대병원 의용공학팀에서 관리번호 또는 사용부서를 기반으로 원내 의료장비의 현황, 예방점검 이력, 수리접수 내역 등을 쉽고 빠르게 조회할 수 있도록 지원하는 Streamlit 기반의 웹 응용 프로그램입니다.

---

## ✨ 주요 기능

### 1. 사용자 인증 및 가입 관리 (Streamlit Authenticator & Bcrypt)
* **안전한 로그인 시스템**: 암호화된 사용자 인증(Cookie 기반 세션 관리)을 지원합니다.
* **가입 신청 및 관리자 승인**: 
  * 계정이 없는 사용자는 회원가입을 신청할 수 있습니다 (`pending_users.yaml`에 대기 상태로 저장).
  * 관리자 계정(`dhkoh`)으로 로그인 시, 사이드바에서 대기 중인 사용자의 가입 신청을 **승인** 또는 **거절**할 수 있습니다.

### 2. 관리번호 개별 장비 검색 및 예방점검 라벨 팝업
* **다양한 검색 방식**:
  * 관리번호 직접 입력 (텍스트 입력 및 Enter/조회 버튼)
  * **URL 쿼리 파라미터 연동**: `?mgm=관리번호` 형식으로 접속 시 자동 검색 지원
  * **📷 카메라/QR 스캔 기능**: 모바일 카메라 촬영 또는 이미지 파일(QR/바코드) 업로드를 통한 자동 번호 인식
* **예방점검 라벨 팝업**:
  * 장비 조회 시 예방점검 라벨(점검일자, 차기점검일, 주기, 위험등급, 정비자 등)이 팝업으로 자동 표시됩니다.
  * 차기 점검일이 임박했거나 경과한 경우 시각적 알림(깜빡이 효과 및 의뢰 권고 문구)을 제공합니다.
  * 폐기 장비(`88`, `77` 부서)의 경우 별도의 상태 표시를 적용합니다.

### 3. 부서별 장비 리스트 조회
* 사용부서별로 등록된 전체 의료장비 목록을 필터링하여 확인할 수 있습니다.
* 주요 요약 정보(관리번호, 장비명, 설치장소, 모델, 제조업체, 자산상태 등)를 표 형태로 제공하며, 원본 전체 데이터 확장 보기 기능을 지원합니다.

### 4. 수리접수 이력 연동 통합 조회
* 최신 의료기기 현황 파일과 다중 수리접수 내역 파일을 통합 로드하여 관리번호별 수리 이력을 최신순으로 정렬하여 제공합니다.
* 예방점검 이력(`Y`)을 교차 분석하여 정확한 최근 점검일 및 차기 점검 주기를 자동으로 계산합니다.

## 📂 파일 구조 및 요구 사항

### 필수 데이터 파일
프로그램 실행 경로에 아래와 같은 형식의 데이터 파일들이 위치해야 합니다.
* **의료기기 현황조회 파일**: `의료기기 현황조회_YYYYMMDD.xlsx` (또는 `.xlsb`, `.xls`)
* **수리접수 내역 파일**: `수리접수 내역_YYYYMMDD.xlsx` (다중 파일 통합 지원)
* **설정 파일**: `config.yaml` (인증 정보 및 쿠키 설정)
* **대기 파일**: `pending_users.yaml` (가입 신청 대기 목록, 자동 생성)

## 🛠️ 기술 스택 (Tech Stack)

* **Language**: Python 3.8+
* **Framework**: Streamlit
* **Data Processing**: Pandas, NumPy
* **Authentication**: `streamlit-authenticator`, `bcrypt`
* **QR/Barcode Decoding**: OpenCV (`cv2`), `pyzbar`
* **Configuration**: PyYAML
